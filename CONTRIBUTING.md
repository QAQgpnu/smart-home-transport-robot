# Contributing

This repository is a compact portfolio reconstruction. Focus contributions on explainability, deterministic behavior, and clear evidence boundaries.

1. Create a focused branch.
2. Run `python scripts/demo.py`.
3. Check that generated files only change for an intentional model change.
4. Explain algorithm or assumption changes in the pull request.

Do not add certificates, personal information, proprietary team files, vendor SDKs, or claims that cannot be supported by public repository evidence.
